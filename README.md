# Taller-git
Sergio Lancheros Botero
Repositorio de práctica del taller de Git.
Materia Backend.
Propósito: registrar la evolución de un pequeño proyecto backend con commits claros.

Sesión 5: Cambio desde GitHub y creación de commit

## Uso del repositorio

Para trabajar con este proyecto:

1. Clona el repositorio con `git clone <URL>`.
2. Antes de empezar a trabajar, actualiza tu copia local con `git pull`.
3. Crea una rama para cada cambio o mejora que vayas a realizar, por ejemplo: `git switch -c nombre-de-la-rama`.
4. Realiza tus cambios, revísalos con `git diff`, y confírmalos con `git add` y `git commit`.
5. Publica tu rama con `git push -u origin nombre-de-la-rama` para compartirla en el repositorio remoto.
